# Apna Khata Advance 📒

Multi-Dimensional Personal Finance, Advance Khata, Committee/Kameti Tracker & Household Budget Management.

## Features
- **Phone + Password Login:** One-time registration with phone number, chosen password, and full name.
- **Row Level Security (RLS):** Har user ka data bilkul isolated aur protected hai. Koi doosra shakhs aap ka hisaab nahi dekh sakta.
- **Advance Lena-Dena Khata:** Personal / Business receivables, payables, and settlement entries with automatic net totals.
- **Committee / Kameti Tracker:** Track pool amounts, monthly installments, total duration, and payout turn.
- **Gharana Aamdan & Kharch:** Track monthly salary/income vs daily expenses (rashan, bills, fee, medicines) with net savings calculation.
- **Modern Responsive Dark UI:** Fast and lightweight mobile ergonomics.

## Deployment Setup

### 1. Supabase Database
In your new Supabase Project SQL Editor, run `supabase_setup.sql`.

### 2. Live Hosting (Vercel)
Connect the GitHub repository `https://github.com/Nabeelyaram/apna-khata-advance` to Vercel and deploy.
